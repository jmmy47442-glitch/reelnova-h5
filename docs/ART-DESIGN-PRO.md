# Admin UI baseline

The administration interface is designed from the conventions of [Art Design Pro](https://github.com/Daymychen/art-design-pro), an MIT-licensed Vue 3, Vite, TypeScript and Element Plus admin template.

This project uses its characteristic information architecture and interaction patterns for the admin surface: grouped sidebar navigation, a utility header, route tabs, compact filter bars, Element Plus tables, status tags, dialogs and responsive sidebar behavior. The customer H5 remains a separate mobile-first experience because the Art Design Pro dashboard shell is not suitable for consumer video browsing.

No third-party demo brand assets or business data are reused. ReelNova-specific pages, styles, data types and interaction logic are implemented in this repository.
