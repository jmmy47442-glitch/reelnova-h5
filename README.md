# ReelNova H5

> 需求版本：V1.0 MVP
>
> 更新日期：2026-08-08
>
> 详细需求：[海外短剧 H5 点播平台需求规格说明书](./%E6%B5%B7%E5%A4%96%E7%9F%AD%E5%89%A7H5%E7%82%B9%E6%92%AD%E5%B9%B3%E5%8F%B0%E9%9C%80%E6%B1%82%E8%A7%84%E6%A0%BC%E8%AF%B4%E6%98%8E%E4%B9%A6.md)

ReelNova 是面向美国市场的移动端竖屏短剧 H5 点播平台。用户可免注册试看，通过 PayPal 按单剧付费解锁；运营人员可在管理后台上传、转码、编辑和上下架内容。

README 用于快速了解项目范围和实施约束。功能细节、字段定义和验收规则以需求规格说明书为准。

## 业务目标

- 支持短剧上传、转码、封面管理、定时发布和上下架。
- 支持 5-6 个可由后台排序和配置的首页内容分区。
- 游客无需注册即可试看，支付时再关联 PayPal 邮箱和匿名访客身份。
- 支持 PayPal Checkout、Webhook 回调、订单状态同步、退款记录和对账。
- 购买单剧后解锁该剧已上架内容，是否包含后续更新由后台配置。
- 支持订单与权益恢复，更换设备或清理缓存后可通过邮箱、订单号或 PayPal 交易号校验恢复。
- 业务数据与域名解耦，更换主域名不影响内容、订单和用户权益。
- 通过私有存储、CDN 私有回源、短时签名地址和访问频控降低盗播风险。

### MVP 不包含

- 原生 iOS/Android App。
- 直播、用户上传、评论、私信和社交关注。
- 订阅制、复杂会员体系和多支付渠道并行结算。
- 复杂广告投放平台和算法推荐训练平台。
- 完全阻止录屏；MVP 的防盗播目标是防止资源直链和批量下载。

| 项目 | MVP 配置 |
| --- | --- |
| 目标市场 | United States |
| 默认地区 | `US` |
| 默认语言 | 美式英语 `en-US` |
| 默认货币 | 美元 `USD` |

## 业务闭环

```text
游客进入首页
  -> 浏览分类和短剧
  -> 进入剧集详情
  -> 免费试看
  -> 播放锁定集时发起 PayPal 支付
  -> 服务端确认回调并发放权益
  -> 解锁短剧并记录观看进度
  -> 在用户中心查看已购内容、订单和支付记录
```

## 用户与权限

| 角色 | 核心能力 |
| --- | --- |
| 游客 | 浏览、试看、发起支付、查看当前设备的购买结果 |
| 已购用户 | 恢复订单、查看已购短剧、继续观看和查看记录 |
| 内容运营 | 上传视频、维护剧集和素材、批量上下架、配置分类标签 |
| 财务/运营管理员 | 查看订单和支付流水、记录退款、导出对账数据、配置价格活动 |
| 超级管理员 | 管理后台账号、域名、PayPal 配置、系统参数和审计日志 |

后台权限遵循最小化原则。删除内容、修改支付配置、退款标记和域名切换等高风险操作必须记录操作人、时间、IP 和变更前后值。

## 用户端 H5

### 导航与首页

- 底部导航：Home、Explore、Library、Profile，需适配手机安全区。
- 首页默认分区：Popular、New Releases、Rankings、Romance、Revenge & Power、US Picks。
- 分区的标题、顺序、显示数量和内容来源由后台配置。
- 手机端默认三列 2:3 竖版封面，显示剧名、播放量、更新集数及 Hot/New/Free/Paid 状态。
- 支持下拉刷新、分页/懒加载、骨架屏、空状态、错误重试和返回后的滚动位置恢复。

### 探索与详情

- 支持按类型、语言和标签筛选，以及 Popular、Newest、Most Watched、Most Purchased 排序。
- 支持按剧名、演员和标签搜索；筛选条件写入 URL 查询参数。
- 详情页展示封面、剧名、标签、热度、简介、演员、分集状态和相关推荐。
- 根据权益显示 Continue Watching、Watch Free 或 Unlock Now。
- 每部剧可配置 0-10 集试看，默认前 3 集免费。

### 播放器

- 默认适配 9:16 竖屏内容，支持 HLS、播放/暂停、进度、音量、清晰度、倍速、全屏和下一集。
- 记录最近观看集数和播放位置，支持网络中断自动重试。
- 每次获取播放地址都由服务端验证试看或购买权益。
- 锁定集不返回可用视频源；权益失效、订单待确认或签名过期时暂停播放。
- 播放地址使用 5-15 分钟有效的短时签名 URL，并支持按需刷新。

### 支付与用户中心

- 支付弹窗显示剧名、封面、解锁范围、原价/活动价、USD 币种和服务条款。
- 使用 PayPal 官方 SDK 或托管按钮，覆盖待支付、处理中、成功、失败、取消、退款中和已退款状态。
- 前端不以 PayPal 跳转结果作为最终支付事实，需轮询本地订单并等待服务端确认。
- 用户中心包含已购短剧、订单记录、支付记录、观看记录、恢复购买、语言/地区、隐私、客服和退款政策。

## 运营管理后台

### 内容管理

- 管理剧名、简介、演员、版权、多种封面、分类标签、目标地区、语言和 SEO 信息。
- 配置试看集数、解锁方式、原价、活动价、地区价、上下架时间。
- 支持单集/批量上传、断点续传、格式校验、转码进度、HLS 多码率和封面截图。
- 剧集状态包含草稿、处理中、待发布、已上架、已下架和版权冻结。
- 删除采用软删除，已产生订单的剧集不得物理删除。

### 运营、财务与系统配置

- 管理首页分区、分类、标签、推荐位、折扣活动和站点全局配置。
- 查看匿名访客/用户、观看记录、已购权益、订单和退款状态。
- 支持 PayPal 沙箱/生产环境切换、Webhook 状态、CSV 导出和按日期/币种对账。
- 支持主域名、备用域名、HTTPS 证书状态、域名验证和强制跳转策略。
- 人工补发权益、解除设备限制和标记客服处理结果必须记入审计日志，不得伪造支付成功。

## PayPal 订单与权益

```text
前端请求创建订单
  -> 服务端校验剧集、价格版本和访客身份
  -> 创建 pending 本地订单和唯一订单号
  -> 服务端创建 PayPal Order
  -> 用户在 PayPal 完成授权
  -> 服务端 capture 或接收 Webhook
  -> 验证金额、币种、商户和订单关联
  -> 幂等更新为 paid 并发放权益
  -> 前端轮询订单状态并刷新播放权限
```

关键规则：

- 一个业务订单只能发放一次有效权益，Webhook、前端回调和后台重试必须幂等。
- 本地订单号、PayPal Order ID、Capture ID 和 Webhook Event ID 必须唯一。
- 金额、币种或商户信息不一致时进入 `risk_review`，不自动解锁。
- PayPal 支付成功但回调延迟时，前端显示 Payment processing，服务端执行补偿查询。
- 订单保存创建时的价格快照，后续改价不影响历史订单。
- 退款状态与权益状态分离；MVP 默认在退款确认后锁定权益。

## 视频处理与分发

```text
私有对象存储中的原始视频
  -> FFmpeg/云转码服务
  -> H.264 + AAC 的 480p/720p 多码率 HLS
  -> CDN 私有回源分发
  -> 服务端生成短时签名地址
  -> H5 播放器
```

- 接收 MP4/MOV 等常见源文件，原始视频不允许使用公开 URL。
- 视频、字幕、封面和海报使用独立存储路径。
- 签名绑定剧集、集数、用户/访客会话和过期时间，播放 API 不返回原始存储地址。
- 支持 Referer、Origin、IP/设备频率和并发设备数检查，记录异常下载行为。

## 推荐技术选型

| 层级 | 推荐语言 | 推荐技术 |
| --- | --- | --- |
| 用户端 H5 | TypeScript | Vue 3 + Nuxt 3 |
| 运营管理后台 | TypeScript | Vue 3 + Vite + Element Plus |
| 服务端 API | Java 21 | Spring Boot 3 |
| 数据库 | SQL | PostgreSQL |
| 缓存与会话 | - | Redis |
| 视频处理 | Java 调度 | FFmpeg + HLS |

### 选型说明

- 用户端需要兼容移动浏览器并支持 SEO 和分享页面，因此采用 TypeScript + Vue 3 + Nuxt 3。
- 用户端和运营后台统一使用 TypeScript/Vue 3，便于共享 API 类型、表单校验、国际化资源和基础组件。
- 服务端需要处理订单事务、Webhook 验签与幂等、权益发放、退款状态和审计日志，因此采用 Java + Spring Boot。
- 视频转码直接使用 FFmpeg，MVP 阶段由 Java 服务投递和调度转码任务。
- Nuxt 3 只承担 H5 渲染和页面服务；支付回调、权益校验和转码任务由 Spring Boot 服务负责。

## 系统边界

```text
用户端 Nuxt 3 H5  ----\
                          -> Spring Boot REST API -> PostgreSQL
运营后台 Vue 3  ----/             |-> Redis
                                               |-> PayPal API/Webhook
                                               |-> 对象存储/转码/CDN
```

服务端 API 统一返回包含 `code`、`message` 和 `request_id` 的错误结构，不向前端返回密钥、原始存储路径或支付敏感字段。

### 核心数据实体

| 实体 | 用途 |
| --- | --- |
| `series` / `episode` | 短剧和分集内容 |
| `category` / `tag` | 分类、标签和运营筛选 |
| `visitor` / `user` | 匿名访客和可恢复用户身份 |
| `order` / `payment_event` | 本地订单和 PayPal 事件 |
| `entitlement` | 用户对单部短剧的播放权益 |
| `watch_history` | 最近集数、播放进度和时间 |
| `admin_audit_log` | 后台高风险操作的变更记录 |

### 核心 API

| 范围 | 主要端点 |
| --- | --- |
| 首页与内容 | `GET /api/home`、`GET /api/categories`、`GET /api/series/{slug}` |
| 播放 | `GET /api/series/{id}/episodes/{episodeNo}/playback` |
| 访客 | `POST /api/visitors/session` |
| 订单 | `POST /api/orders`、`GET /api/orders/{orderNo}`、`POST /api/orders/{orderNo}/restore` |
| 用户中心 | `GET /api/me/library`、`GET/POST /api/me/watch-history` |
| PayPal | `POST /api/paypal/webhook` |
| 管理后台 | `/admin/api/series`、`/admin/api/orders`、`/admin/api/reconciliation`、`/admin/api/site-config` 等 |

## 设计与交互基线

- 移动端优先，采用深色、高密度竖版海报的沉浸式观影界面。
- 首屏直接展示分类、短剧卡片和播放量，不制作营销型落地页。
- 按钮最小可触区域为 44x44 px，底部导航和播放控件不得被系统手势区域遮挡。
- 卡片标题最多两行，价格、集数、剧名和标签需使用真实长度测试溢出。
- 核心组件覆盖默认、加载、空数据、错误、禁用、已购、已锁定和网络重试状态。
- 价格、类别、文案、颜色、间距、字号和站点品牌通过配置或设计 token 管理。

## 非功能要求

### 性能与可用性

- 美国 4G 网络下，首页首屏 P75 < 2.5 秒，播放首帧 P75 < 5 秒。
- 图片使用 WebP/AVIF 并按设备返回合适尺寸，首张封面优先加载。
- API 支持超时、重试和降级，支付页失败不影响已购内容浏览。
- 监控地区、设备、浏览器、CDN 节点、首帧时间、卡顿率和播放失败率。

### 安全与隐私

- 全站 HTTPS，PayPal Secret、对象存储密钥和签名密钥使用密钥管理服务或加密环境变量。
- Webhook 必须校验 PayPal 签名，拒绝未验证来源。
- 采集最少化个人信息，日志脱敏，不记录完整支付卡信息或 PayPal 密钥。
- 提供隐私政策、服务条款、退款政策、版权投诉和数据导出/删除的人工处理流程。
- 按地区配置内容可见性、年龄提示、内容分级和不可售区域。

## 埋点与指标

- 内容漏斗：分区/卡片曝光、卡片点击、详情打开、试看开始/完成、锁片触发。
- 支付漏斗：支付弹窗打开、PayPal 点击、支付成功/失败/取消、回调延迟。
- 播放质量：播放开始、首帧、中断、完播、下一集、首帧时间、卡顿率和失败率。
- 核心经营指标：首页到详情点击率、试看完成率、锁片转化率、支付成功率、退款率、单剧/地区收入。

## MVP 验收要点

- 手机竖屏可完成首页浏览、分类筛选、详情查看、游客试看、PayPal 支付和已购播放闭环。
- 支付回调确认后解锁，刷新页面后权益仍有效，用户可恢复历史购买。
- 后台可管理剧集、分集、素材、试看数、价格、分类标签、首页分区和上下架。
- 后台可查询订单/退款、导出对账、切换 PayPal 环境、查看 Webhook 状态和配置域名。
- 320 px 宽度无横向溢出、文字重叠和底部导航遮挡。
- 视频源文件不公开，播放地址为短时签名 URL。
- 重复 Webhook 不重复发放权益，支付金额不一致时不自动解锁。
- 所有高风险后台操作都可在审计日志中追溯。

## 开发与交付阶段

1. 产品和视觉基线：信息架构、移动端 UI、设计 token、英文文案和全部组件状态。
2. MVP 开发：内容管理、HLS 转码/CDN、游客会话、PayPal 订单权益、首页、探索、详情、播放和用户中心。
3. 联调和上线：PayPal 沙箱、真机/弱网/美国节点测试、生产域名、HTTPS、CDN、监控、备份和回滚。
4. 运营增强：多语言、多币种、折扣码、推荐策略、收藏、评论和水印。
